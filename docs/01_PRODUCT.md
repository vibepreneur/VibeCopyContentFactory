# Product Brief — v0.5

**Продукт:** автоматический контент-завод вертикальных видео для Telegram-бота Vibe Copy. Пользователь проекта вручную выбирает музыку в каталоге соцсети и публикует; остальные текст, титры, сцены, рендер, сохранение — автоматические. Админ-бот отдельный от публичного Vibe Copy.

## Результат
- Команда в Telegram создаёт партию 10 ~30-секундных видео 1080×1920/30fps, H.264 MP4 без трека музыки; устойчивость при сбоях/перезапуске.
- Результаты исходных генераций, скринкастов, анимаций, итоговые masters хранятся локально и повторно используются.
- Пользователь видит 10 AI-кандидатов на согласование, управляет retry/reject без ручного монтажа. Принятые автоматически переходят в видеопроизводство.

## Режим А: production
1. Из заранее подготовленных пар original + reference (начать с ~50 пар) выбираются 10 новых слотов.
2. Каждая пара через Vibe Copy Worker на VPS получает AI-result. Публичные кредиты/платежи не затрагиваются.
3. Тройка original/reference/result показывается человеку в отдельном Telegram admin-bot. `APPROVE` или `RETRY` (новая платная попытка той же пары) или `REJECT_FINAL`.
4. **Каждый APPROVE сразу** разрешает Remotion render скринкаста и монтаж, без ожидания остальных девяти. `REJECT_FINAL` слот закрывает, без скрытого авто-дополнения до 10.
5. Анимированный аватар создаётся из статичного (Kling, через API, или уже заранее созданного при доступном reusable asset по явно выбранной политике), добавляются hook, explanatory text, CTA. Сохранять сам avatar MP4, тройку фото, screencast MP4, final MP4, ключи метаданных, бюджеты.

## Режим Б: recombination
- Использует **только ранее одобренные** скринкасты и анимированные аватары, готовые хуки и сценарии.
- AI API не вызываются. Проверка полной уникальности `avatar_clip_id+screencast_id+hook_id+scenario_id+revision`, в приоритете ранее неиспользованные avatar+screencast пары. Точный дубль не выпускать.

## Ограничения
- Не генерировать миллионы роликов заранее; библиотека растёт по требованию.
- Две человеческие проверки: AI-result и финальный MP4. Не требуется автоматическая художественная AI QA.
- Плохие результаты AI хранятся временно до TTL; технический след затрат сохраняется.
- Права на фото/аватаров и использование образов обязательны перед публичным использованием.

## Быстрый MVP
Обязательны: один рабочий 30s монтажный шаблон, базовая библиотека+SQLite, точная копия v9 Remotion, admin workflow, Worker API, режимы A/B, CPU-safe очередь, шаблонный auto captions. Можно отложить: 4 монтажных сценария, 10 новых вариаций каждого аватара, LLM-huk generation, автоматизацию соцсетей, красивую web-панель, сложную аналитику.
