# Установка патча v8 → v9 поверх работающего проекта

1. Закройте Remotion Studio (`Ctrl+C` в терминале VS Code).
2. Сделайте резервную копию папки v8 или коммит в Git.
3. Распакуйте патч. **Содержимое папок `src`, `cases`, `tools`, `preview` скопируйте в такие же папки проекта v8**. Файл `package.json` положите в корень, рядом с прежним `package.json`. Согласитесь на замену одноимённых файлов.
4. Фотографии `public/assets` **заменять не нужно** — они сохраняются из v8.
5. Обратите внимание: патч содержит `cases/CASE_001.json` и `cases/CASE_SHORT.json`. Если меняли тексты или пути самостоятельно, сначала сохраните свои JSON. Для перехода достаточно установить в своём JSON:

```json
"show_start_screen": false,
"ui": {
  "video_layout": "social_fill_1080x1920",
  "show_status_bar": false,
  "social_fill_mode": "adaptive_reflow"
}
```

Остальные ключи внутри `ui` оставьте без изменений.

6. В терминале из корня проекта выполните:

```bash
npm run check:v9
npm run dev -- --no-open
```

Откройте http://localhost:3000 и композицию `VibeCopySocialFill`.

7. Экспорт готового MP4:

```bash
npm run render
```

Результат: `out/CASE_001-social-fill-1080x1920.mp4`.

`npm install` обычно не нужен: версии зависимостей Remotion из v8 не менялись. Если в папке нет `node_modules`, выполните `npm install`.

**Не обрезайте верх MP4 после рендера:** строка состояния уже полностью исключена из Social Fill, а освободившееся место используется интерфейсом чата.
